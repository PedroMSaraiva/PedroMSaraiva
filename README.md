## Projects

Here are a few projects I've worked on:

*   **[Landing Base Detection System for UAV](https://github.com/PedroMSaraiva/base_detection/tree/main):**  In collaboration with the Flying Robots team of Pequi Mecanico, I developed a landing base detection algorithm and a system that corrects the base's position relative to the drone. This system projects the absolute position of the base to the drone, enabling efficient and accurate landings.  _Keywords: UAV, Computer Vision, Object Detection, Robotics, Position Correction._

*   **[Adversarial Attacks for Image Classification Networks](https://github.com/PedroMSaraiva/seminario-esquizofrenia):**  We conducted a study on adversarial attacks in image classification neural networks.  We evaluated the effectiveness of various adversarial attack algorithms (FGM, PGD, and DeepFool) and their transferability across different neural network architectures. The project yielded several interesting insights into the robustness and vulnerabilities of these models. _Keywords: Adversarial Attacks, Neural Networks, Image Classification, Robustness, Transferability._

*   **[Heuristics Classes](https://github.com/PedroMSaraiva/heuristics-classes):** This repository contains a series of heuristic and multi-objective modeling activities. In the final project, I applied a performance evaluation process to a Multiple Linear Regression (MLR) model before and after applying a Genetic Algorithm for feature selection. I also implemented hyperparameter fine-tuning for the Genetic Algorithm. _Keywords: Heuristics, Multi-objective Optimization, Genetic Algorithm, Feature Selection, Hyperparameter Tuning, Machine Learning, Regression._

*   **Professional Experience with CEIA (Excellence Center of Artificial Intelligence):** During my undergraduate studies, I participated in several CEIA projects, including: chatbot development with RAG, system and DevOps development; developing LLMs for labor law processes and traditional ML models to assist lawyers; developing a benchmark system for VLMs to extract property features to assist the City of Goiânia in calculating IPTU (property tax); and assisting with numerous events that contribute to the dissemination and promotion of technology in the country. _Keywords: Chatbot, RAG, LLM, DevOps, VLM, Benchmarking, Property Feature Extraction, Machine Learning, Natural Language Processing, Event Support._
